# SafeWalk

Приложение Ренаты и Даны для планирования городских поездок: карта, поиск адресов, пешеходные и автомобильные маршруты, выбор близкого контакта и подтверждение прибытия.

Работает на Android, iOS и в браузере. Клиент написан на React Native и Expo SDK 57, сервер — на Node.js и Express. Аккаунты и сессии хранятся в SQLite.

Данные карты: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). [Маршруты FOSSGIS](https://routing.openstreetmap.de/about.html).
